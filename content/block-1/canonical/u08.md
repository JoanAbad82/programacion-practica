# U08 — Colecciones

## Objetivo
Comprender cómo almacenar varios elementos dentro de una misma estructura.

Una **colección** puede contener varios valores relacionados.

Python:

```python
acciones = ["AAPL", "MSFT", "NVDA"]
```

PowerShell:

```powershell
$acciones = @("AAPL", "MSFT", "NVDA")
```

## Índices
Un **índice** permite acceder a una posición.

```python
acciones[0]
```

devuelve el primer elemento: `"AAPL"`.

En los ejemplos introductorios, el primer índice es `0`.

## Conceptos esenciales
- colección
- lista
- índice

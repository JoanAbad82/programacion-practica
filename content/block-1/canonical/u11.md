# U11 — Sistema, archivos y rutas

## Objetivo
Aprender a orientarse en el sistema de archivos y combinar comandos básicos de PowerShell.

Una **ruta** representa la ubicación de un archivo o carpeta.

Ruta absoluta:

```text
C:\Users\Ana\Documents\datos.txt
```

Ruta relativa:

```text
datos\archivo.txt
```

## Comandos básicos

```powershell
Get-Location
```

consulta la ubicación actual.

```powershell
Get-ChildItem
```

muestra elementos de una ubicación.

```powershell
Set-Location "C:\Users\Ana\Documents"
```

cambia la ubicación de trabajo.

## Pipeline

```powershell
Get-ChildItem *.txt | Sort-Object Name
```

El símbolo `|` pasa los resultados del primer comando al siguiente.

## Ayuda

```powershell
Get-Help Get-ChildItem
Get-Command
```

Programar no significa memorizarlo todo: saber localizar información técnica también es una habilidad.

# U07 — Condiciones

## Objetivo
Hacer que un programa ejecute diferentes instrucciones según una condición.

Una **condición** es una expresión cuyo resultado puede interpretarse como verdadero o falso.

```python
edad >= 18
```

## `if`
`if` ejecuta un bloque cuando se cumple una condición:

```python
if edad >= 18:
    print("Adulto")
```

## `else`
`else` define la alternativa cuando la condición no se cumple:

```python
if edad >= 18:
    print("Adulto")
else:
    print("Menor")
```

En PowerShell la idea es equivalente:

```powershell
if ($edad -ge 18) {
    Write-Host "Adulto"
}
```

## Conceptos esenciales
- condición
- if
- else

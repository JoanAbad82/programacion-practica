# U05 — Entrada y salida

## Objetivo
Entender el flujo básico de información en un programa.

Modelo:

**Entrada → Procesamiento → Salida**

La **entrada** es la información que recibe el programa. El **procesamiento** son las operaciones realizadas con esos datos. La **salida** es la información que el programa produce o muestra.

Python:

```python
nombre = input("Nombre: ")
print("Hola", nombre)
```

PowerShell:

```powershell
$nombre = Read-Host "Nombre"
Write-Host $nombre
```

## Ejemplo de procesamiento

```python
precio = 10
cantidad = 3
total = precio * cantidad
print(total)
```

La entrada son los datos, la multiplicación es procesamiento y `print()` produce salida.

## Conceptos esenciales
- entrada
- procesamiento
- salida
- modelo Entrada → Procesamiento → Salida

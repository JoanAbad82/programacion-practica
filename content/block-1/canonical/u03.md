# U03 — Sintaxis y comentarios

## Objetivo
Entender por qué el código debe respetar unas reglas de escritura y cómo documentarlo.

La **sintaxis** son las reglas que determinan cómo debe escribirse correctamente el código. Símbolos como paréntesis, comillas, dos puntos o guiones pueden tener significado.

## Comentarios
En Python y PowerShell podemos usar `#` para escribir comentarios:

```python
# Mostrar un mensaje
print("Hola")
```

El comentario sirve para explicar o documentar el código y normalmente no se ejecuta.

## Indentación en Python
En Python la indentación no es solo estética: forma parte de la estructura del programa.

```python
if edad >= 18:
    print("Adulto")
```

La línea indentada pertenece al bloque del `if`.

## Conceptos esenciales
- sintaxis
- comentario
- indentación

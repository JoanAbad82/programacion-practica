# U10 — Funciones

## Objetivo
Organizar instrucciones en bloques reutilizables.

Una **función** agrupa instrucciones destinadas a realizar una tarea.

Python:

```python
def saludar():
    print("Hola")
```

Esto **define** la función. Para ejecutarla hay que realizar una **llamada**:

```python
saludar()
```

## Parámetros y argumentos

```python
def saludar(nombre):
    print("Hola", nombre)

saludar("Ana")
```

`nombre` es el **parámetro**. `"Ana"` es el **argumento**.

## `return`

```python
def total(precio, cantidad):
    return precio * cantidad
```

`return` devuelve un resultado desde la función.

## Conceptos esenciales
- función
- llamada
- parámetro
- argumento
- return

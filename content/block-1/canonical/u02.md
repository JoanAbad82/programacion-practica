# U02 — Terminal, comandos y scripts

## Objetivo
Distinguir entre ejecutar una instrucción directamente y guardarla para reutilizarla.

## Terminal y comandos
Una **terminal** o **consola** es un entorno textual desde el que podemos introducir y ejecutar comandos.

En PowerShell podemos escribir:

```powershell
Get-Date
```

y pulsar `Enter` para ejecutar el comando directamente.

Un **cmdlet** es un tipo de comando propio de PowerShell. Muchos siguen la convención **Verbo-Sustantivo**:

```powershell
Get-Location
Set-Location
Get-ChildItem
```

## Scripts
Cuando queremos conservar varias instrucciones para reutilizarlas, podemos guardarlas en un **script**.

Extensiones habituales:

- Python: `.py`
- PowerShell: `.ps1`

Ejecutar comandos directamente en una terminal **no crea automáticamente un script**.

## Conceptos esenciales
- terminal
- comando
- cmdlet
- Verbo-Sustantivo
- script

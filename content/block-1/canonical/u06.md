# U06 — Operaciones y expresiones

## Objetivo
Utilizar operaciones sencillas y comprender qué produce una expresión.

Operadores matemáticos básicos:

- `+` suma
- `-` resta
- `*` multiplicación
- `/` división

Una **expresión** combina valores, variables y operadores para producir un resultado.

```python
total = precio * cantidad
```

## Comparaciones
Python:

```text
==  !=  >  <  >=  <=
```

PowerShell:

```text
-eq  -ne  -gt  -lt  -ge  -le
```

Una comparación produce un resultado lógico.

## Asignar no es comparar

```python
edad = 20
```

asigna un valor.

```python
edad == 20
```

comprueba igualdad.

Esta diferencia es fundamental.

## Conceptos esenciales
- operadores
- expresión
- comparación
- asignación frente a comparación

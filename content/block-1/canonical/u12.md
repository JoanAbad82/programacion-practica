# U12 — Errores, depuración e IA

## Objetivo
Aprender a analizar problemas de código y pedir cambios técnicos de forma precisa.

## Tipos de error
**Error de sintaxis:** el código incumple las reglas de escritura.

**Error de ejecución:** el problema aparece mientras el programa se está ejecutando.

**Error lógico:** el programa puede ejecutarse, pero produce un resultado incorrecto.

## Depuración
Proceso básico:

1. leer el error;
2. localizar la zona afectada;
3. identificar qué debía ocurrir;
4. comprobar valores y variables;
5. cambiar una cosa cada vez;
6. volver a ejecutar.

Antes de modificar código debemos comprender qué hace.

## Trabajar con IA
Una petición técnica útil debe indicar, cuando sea relevante:

- lenguaje;
- objetivo;
- elemento afectado;
- comportamiento esperado;
- restricciones.

Ejemplo:

> Modifica únicamente `calcular_total()` para incluir una comisión. Mantén intacto el resto del programa.

Limitar el alcance reduce cambios accidentales.

## Conceptos esenciales
- error de sintaxis
- error de ejecución
- error lógico
- debugging
- leer antes de modificar
- precisión al trabajar con IA
- cambio seguro

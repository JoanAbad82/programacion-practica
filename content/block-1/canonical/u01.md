# U01 — El ordenador y el código

## Objetivo
Comprender qué significan **programa**, **código**, **lenguaje de programación** e **instrucción** y cómo se relacionan.

## Ideas clave
Un **programa** es un conjunto de instrucciones que un ordenador ejecuta para realizar una tarea. Esas instrucciones están escritas como **código** utilizando las reglas de un **lenguaje de programación**.

Una **instrucción** expresa una acción concreta. Por ejemplo, mostrar un mensaje, obtener la fecha o realizar un cálculo.

## Ejemplos

Python:

```python
print("Hola")
```

PowerShell:

```powershell
Write-Host "Hola"
```

Ambas instrucciones persiguen una finalidad similar: mostrar un mensaje. La sintaxis cambia porque pertenecen a lenguajes diferentes.

## Interpretación
No debemos confundir el **código** con el **resultado**. El código describe qué debe hacerse; al ejecutarlo puede producir una salida.

## Conceptos esenciales
- programa
- código
- lenguaje de programación
- instrucción

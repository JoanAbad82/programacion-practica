# U09 — Bucles

## Objetivo
Evitar repetir manualmente la misma instrucción muchas veces.

Un **bucle** permite repetir instrucciones. Cada repetición individual es una **iteración**.

Python:

```python
for accion in acciones:
    print(accion)
```

`accion` representa el elemento actual durante cada iteración.

PowerShell:

```powershell
foreach ($accion in $acciones) {
    Write-Host $accion
}
```

La sintaxis cambia, pero la lógica es la misma: recorrer los elementos de una colección.

## Conceptos esenciales
- bucle
- for
- foreach
- iteración

# U04 — Variables y datos

## Objetivo
Comprender cómo guardar información con variables y reconocer tipos de datos básicos.

Una **variable** es un nombre utilizado para almacenar y reutilizar un valor.

Python:

```python
precio = 100
```

PowerShell:

```powershell
$precio = 100
```

El signo `=` realiza una **asignación**. Una variable puede recibir un nuevo valor:

```python
precio = 100
precio = 120
```

Después, `precio` vale `120`.

## Tipos básicos
- **string**: texto, por ejemplo `"Ana"`
- **entero**: número sin parte decimal, por ejemplo `10`
- **decimal/float**: número con parte decimal, por ejemplo `19.95`
- **booleano**: verdadero o falso

Python usa `True` y `False`. PowerShell usa `$true` y `$false`.

## Conceptos esenciales
- variable
- asignación
- string

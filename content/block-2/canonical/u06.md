# U06 — Datos estructurados con JSON

## Objetivo
Trabajar con datos jerárquicos preservando tipos, estructura y validaciones mínimas.

## Conceptos canónicos
- **B2-U06-JSON-OBJECTS-ARRAYS:** distinguir objetos clave-valor y listas ordenadas.
- **B2-U06-JSON-PARSE:** deserializar texto JSON válido a estructuras nativas.
- **B2-U06-JSON-SERIALIZE:** convertir estructuras nativas a JSON válido.
- **B2-U06-NESTED-ACCESS:** navegar estructuras anidadas validando niveles y claves.
- **B2-U06-JSON-TYPES:** string, number, boolean, null, object y array.
- **B2-U06-JSON-SHAPE-VALIDATION:** comprobar campos y tipos básicos antes de usarlos.

## Herramientas
Python: json.load(), loads(), dump(), dumps().
PowerShell: ConvertFrom-Json, ConvertTo-Json y uso consciente de -Depth.

## Práctica
Leer una configuración JSON, validar campos obligatorios y producir un resumen legible. Texto JSON y objeto deserializado no son lo mismo.
